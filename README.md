# Recent Workspace Widget (最近工作空间启动器)

> 🎨 **白色极简风格 · 本地私密索引 · 键盘原生操控 · 一键启动 AI 编程 Agent**

平时在不同项目之间切换写代码，无需每次手动打开终端、切换路径或翻找目录。**Recent Workspace Widget** 让你按下快捷键即可唤出面板，检索最近使用的代码项目与工作空间，**选中想用的 Agent，直接启动！**

---

## ⚡ 极简上手指南

### 第一步：呼出 / 隐藏窗口
无论你在任何软件界面中，按下全局热键：
> ⌨️ **`Alt + W`**（或 `Alt + Space`）随时唤出与隐藏面板。

### 第二步：选择你想使用的 Agent
窗口右上角提供 Agent 模式切换栏（默认自动选中系统中第一个真实安装的 Agent）：
- **`OpenCode`**：启动 OpenCode AI 终端
- **`Claude Code`**：启动 Claude 终端交互（仅真实安装 CLI 时可用）
- **`Codex`**：启动 OpenAI Codex 编程环境
- **`VS Code`**：直接在 VS Code 编辑器中打开当前项目

> 💡 *提示：未安装或环境变量中未配置的 Agent 会自动标记为未安装，无法误启动；搜索框为空时按键盘 `Tab` 键可在已安装的 Agent 之间顺畅循环切换。*

### 第三步：搜索与启动项目
- 在搜索框中输入项目名称、**中文拼音首字母**（如“人力资源”输入 `rlzy`）或路径关键字；
- 鼠标**单击**卡片：仅选中该项目；
- 鼠标**双击**卡片 或 按键盘 **`Enter`（回车）**：以当前选中的 Agent 启动项目；
- 支持键盘 **`↑` / `↓`** 移动选择，**`PageUp` / `PageDown`** 快速翻页；
- 也可以按 **`Alt + 1~9`** 快速启动前 9 个对应序号的项目。

## 🎮 快捷键与交互一览

| 操作 | 快捷键 / 鼠标操作 | 效果说明 |
|---|---|---|
| **呼出 / 隐藏面板** | <kbd>Alt</kbd> + <kbd>W</kbd> / <kbd>Alt</kbd> + <kbd>Space</kbd> | 快速唤醒或最小化面板，不阻塞主线程 |
| **启动项目** | 敲 <kbd>Enter</kbd>（回车）或鼠标**双击** | 以当前选中的 Agent 在独立终端中打开项目 |
| **选中项目** | 鼠标**单击** 或 <kbd>↑</kbd> / <kbd>↓</kbd> | 仅移动选择光标，防止误触启动 |
| **翻页移动** | <kbd>PageUp</kbd> / <kbd>PageDown</kbd> | 快速向上或向下移动 6 个项目 |
| **切换 Agent** | 鼠标点击右上角标签 或 按 <kbd>Tab</kbd> | 在已安装的 Agent 间切换（未安装自动禁用） |
| **选序号启动** | <kbd>Alt</kbd> + <kbd>1~9</kbd> | 直接启动列表前 9 个项目 |
| **右键菜单** | 鼠标**右键**点击卡片或空白处 | 快捷启动指定工具、复制路径、打开资源管理器、刷新与退出 |
| **复制项目路径** | 按 <kbd>Ctrl</kbd> + <kbd>C</kbd> | 复制当前选中项目的绝对路径到剪贴板（悬浮亦可查看完整路径） |
| **打开文件夹** | 按 <kbd>Ctrl</kbd> + <kbd>E</kbd> | 在 Windows 文件资源管理器中打开项目目录 |
| **清空 / 关闭** | 按 <kbd>Esc</kbd> | 搜索框有内容时清空文字；搜索为空时隐藏窗口 |
| **刷新列表** | 按 <kbd>F5</kbd> 或右键菜单“刷新” | 重新后台扫描工作空间，并在标题栏提示刷新时间 |

## 🔒 隐私与安全性说明

1. **本程序本身纯本地运行**：源码不包含 HTTP/HTTPS 网络请求、云端上传、遥测或使用统计代码。用户主动启动的第三方 Agent 可能有自己的联网或遥测行为，不属于本程序可控制的范围。
2. **数据最小化**：仅在本地读取工作空间路径、项目元数据和必要的时间戳；不会读取 Claude 会话文件、代码文件正文、Token 或密钥。工作空间完整路径会显示在本地界面，并在用户主动启动 Agent 时作为工作目录传给该 Agent。
3. **直接进程启动**：Agent 通过进程参数和工作目录直接启动，不再生成包含工作空间路径的临时批处理文件。

## 🌟 核心特性与技术实现

1. **白色极简设计**：浅灰微绿点缀的高清晰度白色 UI，针对 100%、125%、150% 等高 DPI 显示进行像素对齐与 ClearType 优化，文字清晰边缘锐利。
2. **严谨的项目鉴权引擎**：统一通过项目描述符（`.git`、`package.json`、`pom.xml`、`Cargo.toml`、`go.mod`、`pyproject.toml`、`.sln`、`.csproj` 等）进行可信度鉴权，自动过滤微信/QQ 缓存、系统目录、回收站、普通下载文件及软件安装目录。
3. **真前台活跃识别**：基于 Win32 真实前台窗口与精确进程标题匹配，不将后台未操作的旧项目错误置顶，保护活跃时间的准确性。
4. **极致流畅低延迟**：后台异步扫描，不卡顿 UI 线程；移除唤起/隐藏主路径中的强制同步垃圾回收与工作集截断，保障频繁唤出的丝滑响应。

## 🛠️ 如何编译与运行

### 方式 1：一键编译（推荐）
直接运行根目录下的 **`build.bat`** 脚本。脚本自动使用 Windows 自带的 `csc.exe` 原生编译器构建 `RecentWorkspaceWidget.exe`，无需配置复杂环境，也不会强制终止其他无关进程。

### 方式 2：使用 .NET SDK
项目支持同时面向 `net472` 和 `net8.0-windows` 框架：
```bash
dotnet build -c Release
```
